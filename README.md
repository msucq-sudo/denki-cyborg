# 電気サイボーグ（プロトタイプ）

電気で動くサイボーグが、ロボットから電力を吸い取りながらダンジョンを進む 3D TPS。
仕様・TODO は `PLAN.md` を参照。

## 遊び方

必要なもの: Node.js 18 以上

```bash
npm install
npm run dev
```

表示された URL（例: http://localhost:5173/）をブラウザで開き、「スタート」を押す。画面をクリックするとマウスで視点操作できる（Esc で解除→一時停止）。

### セーブと再開

進行・取得物・強化・装備の変更時に自動セーブします。次回、タイトルの「つづきから」で最後に保存した進行から再開できます。研究所1階は進行を更新した位置、収容所などはステージのチェックポイントから再開し、戦闘中の敵のHPはリセットされます。
セーブは同じブラウザ・同じURLの保存領域（localStorage）に1枠です。プライベートブラウズやブラウザデータの削除では残りません。「はじめから」は新しい進行が保存されると既存データを上書きします。

| 操作 | キー |
|---|---|
| 移動 / 視点 | WASD / マウス |
| 射撃（長押しで溜め撃ち） | 左クリック |
| 吸収アーム（発射 / 解除） | E |
| グラップル | 壁・天井・高台の縁を狙って E（LB）。どこでも刺さる（低い縁ならよじ登る）。引き寄せ中に E／Space で中断。天井はぶら下がり→E／Space で離す（電力2、待ち0.6秒、射程22m） |
| アームで拾う | 歯車・メタルを狙って E（LB）。掴んで手元まで引き寄せる |
| 照準（長押しでズーム） | 右クリック |
| 逆流（吸収中に長押し） | F |
| ハッキング（赤い敵に吸収アームをつないだ状態で、表示されたコードを順に入力。ミスで最初から） | Q T G Z X V B 4 |
| 回避 | C |
| ダッシュ | Shift（長押し、移動中のみ低消費） |
| ジャンプ（空中で長押し：ジェットパックで滞空） | Space |
| オートエイム（スカウターは常にON） | 2 |
| 武器の切り替え（前 / 次。持っている武器が2つ以上のとき） | 1 / 3 |
| スキル発動（選択中のスキル。今はバキュームのみ。仮の割り当て） | Y |
| 一時停止 / 操作表示の切替 | P / H |

### 強化画面（2階のベッドで眠ると開く）

| 操作 | キーボード | コントローラー |
|---|---|---|
| 行を選ぶ | W S / ↑ ↓ | 十字キー上下 / Lスティック |
| 項目（GUN・BODY・ARM・SKILL）を切り替える | A D / ← → / Q E | 十字キー左右 / LB RB |
| 強化する（歯車を使う） | Enter / Space | A |
| 閉じる（ベッドから起きる） | Esc / R | B |
| マウス | 行にホバーで選択、クリックで強化。右側のモデルはドラッグで回せる | — |

GUN・BODY・ARM はレベルを上げるだけ（数値はまとめて上がる）。SKILL は強化するスキルを選んで上げる。歯車が足りない・最大レベルのときは揺れて音が鳴る。

**バキューム**（スキル）：自分を中心とした半径8mの円の中にいる敵全員から、1.5秒かけて電力を吸い取る（1体あたり最大36、得られる電力は吸った量の50%・1回で最大60。吸い尽くした敵は倒れて +4）。仲間（ハッキングした敵）は吸わない。再使用まで14秒。数値は `src/config/balance.ts` の `VACUUM`。入手前はロック表示で使えない（確認用：URL に `?unlock=vacuum`、またはコンソールで `__game.unlock('vacuum')`。`?unlock=all` で武器もすべて所持）。

吸収中（アームが刺さっている間）は、撃てない・移動が遅い・ジャンプ／回避／ダッシュ／ジェットパック不可。

## 確認用ページ（`npm run dev` 中）

| ページ | 内容 |
|---|---|
| `/bestiary.html` | 敵図鑑（見た目・パラメーター・倒すのに必要な弾数など） |
| `/spark.html` | スパークの3Dモデル |
| `/lab.html` | スパークの研究室（会話シーン用） |
| `/?level=floor1` | 研究所1階（ガイド付きチュートリアル階）。スタート通路の敵2体を倒してゲートを開ける → 南東エリア（行き止まりの歯車で罠）→ 右の部屋（下→上の罠、一方通行）→ 大広間（エレベーターは電源なし→西の連絡通路が開く）→ 脇の細い部屋の電源を撃つ／吸収アーム(E)で電気を送る → 左下の罠 → 左上で歯車 → エレベーター前の最終戦 → クリア。罠戦は閉じ込め（赤い警報照明＋サイレン、`LOCKDOWN.enabled` で切替）。歯車7個 |
| `/maps.html` | 研究所マップのまとめページ（1階・2階 × 平面図・3D をタブで切替。`#2-3d` のように指定も可） |
| `/map.html` | 1階のマップビューア（俯瞰・フリーカメラ WASD+右ドラッグ、当たり判定/敵配置/歯車マーカーの切替） |
| `/sfx.html` | 効果音ボード（全効果音の試聴） |
| `/stats.html` | データ一覧（プレイヤー・武器・機能・敵の全数値） |
| `/?level=floor2&gears=10` | 2階（サイボーグ改造室）。中央のベッドで B（キーボードは R）→ 眠ると強化画面が開く。`gears=N` で歯車 N 個から始められる（確認用）。コンソールで `__game.openUpgrade()` でもベッドなしで開ける |

## 開発用コマンド

| コマンド | 内容 |
|---|---|
| `npm run build` | 型チェック＋本番ビルド（`dist/`） |
| `npm test` | 単体テスト（Vitest） |
| `node tests/e2e/playthrough.mjs` | ボットによる通しプレイ確認（ヘッドレス Chromium。パスは環境に合わせて変更） |
| `node tests/e2e/visual.mjs` | 吸収・逆流・スカウター・溜めの見た目スクショ |

調整用の数値はすべて `src/config/balance.ts` にある。
