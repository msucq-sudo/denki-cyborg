SELLING POINT 1吸収と攻撃の駆け引き

電気は弾薬でもあり、体力のような資源でもある。

  • 撃つ・避ける・飛ぶ・見る、すべてに電気を使う
  • 電気は自然に回復しない
  • 敵から吸うか、撃つか。常に判断する

= 遊ぶだけで「電気の大切さ」が体感できる
