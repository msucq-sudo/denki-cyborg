SELLING POINT 1電力を管理しながら戦う、ハラハラのゲーム性

電気は弾であり、命綱。

  • 撃つほど電力は減る
  • 吸えば増える。でも吸っている間は無防備
  • 送電は強力だが、一気に電力を使う
  • 電力は自然に回復しない

「あと1発撃てる？ それとも吸う？」
常にギリギリの判断が生まれる。

= 遊ぶだけで「電気の大切さ」が体感できる

SELLING POINT 3電気を送って謎を解く、アトラクションの楽しさ

sp_puzzle.pngCodexで生成予定
（装置に送電して扉が開く場面）

電気は戦うためだけじゃない。
ステージそのものを動かす力になる。

  • 止まった扉やリフトに送電して動かす
  • 動いている罠から吸収して止める
  • グラップルやジェットパックで高い所へ
  • 寄り道の先には強化アイテム

戦闘と同じ操作で謎が解けるので、覚えることは増えない。
