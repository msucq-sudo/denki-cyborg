## 3. 進行ルート

### 正規ルート
1. **建物の外 → 左側の入口 → A**。赤ウォーカー（敵）がいる。ハッキングすれば仲間。
2. **A → E**（縦通路の途中で**バキューム**入手）
3. **E → F** で**キー②**
4. A に戻り **A → B** で**キー①**（順番は自由）
5. **B → C**、**キー2本そろうと**青い扉が開く → 縦通路 → **D**
6. **D → H**：ビーマー2体＋多数の敵（中ボス戦）。全滅 → **Hの赤斜線から2階へ**

### 隠しルート（キー不要）
- **F → G → D**：Gの天井付近の隠し通路をグラップルで抜けて D へ。**キー扉を通らずに済む**（それでOK）。赤ウォーカーを仲間にしていれば G で案内してくれる。

### 寄り道
- **I**：E から斜め通路。レーザー網を電力源2つの吸収で解除 → **歯車**
- **J**：C の右下隅の脆い壁を溜め撃ちで破壊 → **歯車**

## 4. ギミック仕様

### 4.0 建物の入口（外 ⇄ A）
- 建物の外側と A をつなぐ。入口は**建物を正面から見て左側**に作る。
- スケッチの A 左上の矢印は無関係（気のせい）。

### 4.1 セキュリティキー扉（C上辺 → D）
- 青い印のドア。**キー2本（BとF）が両方そろうと開く**。
- 足りないときは扉に近づくと「キーが必要（1/2）」のようにトースト表示。
- 隠し方（未決定）：壁の裏、箱の上、グラップルでしか届かない高所 など。

### 4.2 脆い壁（J）
- Cの右下隅の壁が脆い。**銃を思い切り溜めて撃つと壊れる**。
- 少しずつ撃つと**ひびが少しずつ入る**演出。

### 4.3 隠し天井通路（G → D）
- GとDだけ壁が天井まである。
- よく見ると**天井付近に人がギリギリ通れる通路**がある。グラップルで天井まで上がると通れる。

### 4.4 赤ウォーカー（A）
- **最初は敵**。ハッキング（既存の「表示されたキー／ボタンを順番通り押す」方式）に**成功するまでは敵のまま**。
- ハッキング成功で仲間になり、**後ろをついてくる**（既存の20秒で解除＝`HACK.allyTime` は、このステージでは解除しない恒久の仲間にする）。
- **倒してしまったらそれで終わり**（敵のうちに倒しても、仲間になった後にやられても、再入手なし）。
- **Gに着いたら G→D の隠し通路を案内**する。
- 仲間への操作：
  - **送電で回復**。限界まで送ったら「最大まで回復しました」。**ショート（過負荷）はしない**。
  - **アームを伸ばしてくっつけて吸収**もできる。

### 4.5 レーザー網と電力源（E ⇄ I）
- EとIの間の斜め通路はレーザーの網目で通れない。
- **機械（レーザー発生装置）2つ＋電力源2つ**。
- **2つの電力源それぞれから電力を吸い取ると網が消える**（両方吸い終わったら解除）。

### 4.6 バキューム（新能力。A→E の通路で入手）
- 発動すると、**自分を中心とした円の中にいる敵全員から電力を吸い取る**。
- 演出：実際に吸い込んでいるように、敵から自分へ電気（光の粒・筋）が流れ込む。敵側は電力が抜けていく見た目。

### 4.6.1 操作（パッド）案
- **武器の切り替え**：十字キー左右。
- **スキル（バキュームなど）**：十字キー下を押している間、画面にスキル選択 UI を出す → 右スティックで選ぶ → **Y で発動**。下を押している間は右スティックで視点を動かさない。
- 反映済み（2026-10-30）：
  - Y はスキル発動専用（仮想キー `Skill`）。調べる操作は B のみ。
  - スカウターは常にON。十字キー左／キーボード 1 の切り替えは削除。
  - 十字キー下を押している間は右スティックで視点が動かない（`input.skillMenuHeld`）。
- 実装済み（2026-10-30）：武器の切り替え（十字キー左右／キーボード 1・3。`src/player/weaponSwitch.ts`）、スキル選択のリング（十字キー下＋右スティック、Y で発動／キーボード Y。`src/abilities/skills.ts`）、バキューム本体（`src/abilities/vacuum.ts`、数値は `VACUUM`）。入手（`world.unlocks.vacuum = true`）を A→E の通路に置くのはステージ側の作業。

### 4.7 中ボス戦（D → H）
- DからHへ向かう途中が戦場。**ビーマー2体**＋他の敵を多数配置。
- 閉じ込め戦（`LOCKDOWN`＝赤い警報照明＋サイレン、全滅まで扉が閉まる）が使える。
- 全滅で H の赤い斜線（2階への出口）が開く。
